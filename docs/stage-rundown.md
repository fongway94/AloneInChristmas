# 《一個人的聖誕》演出流程與舞台提示

此表是視覺與舞台協作參考，不取代導演最終劇本。時間是建議，不是自動計時。實際以演員對白、禱告與現場節奏為準。網頁的每個畫面皆人工推進，PowerPoint 另有逐則訊息投影片與前後黑場。

## 第一幕：孤獨與現實（約 2 分鐘）

| 畫面 | 演員與操作提示 | 聲音／燈光建議 |
|---|---|---|
| 01 一個人的房間 | 女孩坐在床邊，想找人說話。 | 冷色、低亮度；可用輕微鬧鐘聲。 |
| 02 別人的相聚 | 看朋友聚會照片，放下手機，抱住枕頭。 | 不要讓聲音打斷表演。 |
| 03 工作訊息 | 訊息逐漸變快；等表演完成才切換。PPT 逐則手動推進。 | 可用訊息聲、電話聲及短暫工作環境音，避免過密。 |
| 04 生活的重擔 | 面對帳單、經濟壓力。 | 保持冷暗。 |
| 05 來不及的消息 | 接到親人離世消息，留出反應時間。 | 可用電話掛斷聲；之後留白。 |
| 06 無法挽留 | 女孩獨自哭泣。 | 降低背景聲，讓表演成為焦點。 |
| 07 我還能依靠誰？ | 提問後畫面淡黑並保持，待演員準備好才進下一幕。 | 讓黑場保留足夠時間。 |

## 第二幕：一個人的聖誕夜（約 2 分鐘）

| 畫面 | 演員與操作提示 | 聲音／燈光建議 |
|---|---|---|
| 08 沒有回覆的邀請 | 看朋友群組訊息，沒有回覆。 | 一次輕微訊息聲。 |
| 09 一個人出門 | 聽到窗外節慶聲後決定出門。 | 遠處節慶音樂、人聲與煙火音效。 |
| 10 熱鬧的街頭 | 配角演朋友、情侶及家庭；女孩穿過人群。 | 暖色街燈，群眾聲低於對白。 |
| 11 人群中的孤獨 | 配角動作漸慢，女孩走到中央。 | 環境聲漸弱，留出字幕閱讀時間。 |

## 第三幕：意外的相遇（約 3 分鐘）

| 畫面 | 演員與操作提示 | 聲音／燈光建議 |
|---|---|---|
| 12 意外的相遇 | 相撞、扶起、關心；再移向長椅。 | 輕微碰撞聲，不宜誇張。 |
| 13 長椅上的陪伴 | 實體長椅就位；男孩詢問，女孩流淚。 | 安靜環境音，留出沉默。 |
| 14 可以為妳禱告嗎？ | 男孩徵求同意，女孩點頭。 | 聚焦對白，逐漸加一點暖光。 |
| 15 為她禱告 | 男孩完整禱告；等演員結束才推進。 | 可用柔和鋼琴，但不要蓋住禱告。 |
| 16 因為耶穌愛妳 | 女孩詢問原因，男孩回答。 | 留出停頓，避免突然變得明亮。 |
| 17 在風雨中不再孤單 | 男孩分享自己的生命見證。 | 背景音量維持低位。 |
| 18 妳的故事還沒有結束 | 男孩鼓勵女孩，字幕出現後留白。 | 暖光緩慢增加。 |

## 第四幕：因為有一道光（約 2 分鐘）

| 畫面 | 演員與操作提示 | 聲音／燈光建議 |
|---|---|---|
| 19 一起去看話劇 | 男孩發現話劇快開始，邀請女孩。 | 可用輕微手機訊息聲。 |
| 20 朋友們來了 | 男孩朋友入場、真誠邀請女孩。 | 呼喊聲可由演員現場演出。 |
| 21 久違的微笑 | 女孩猶豫、點頭，露出微笑。 | 溫暖但克制；困難沒有突然消失。 |
| 22 一起走向前 | 眾人走向出口。 | 可漸入有授權、溫暖且有盼望的音樂。 |
| 23–26 結尾字幕 | 四句依次手動出現。最後一句保持，準備交接後再進黑場。 | 讓每句有閱讀時間；音樂按現場需要收束。 |

## 交接及排練

1. 如果主辦方以 PowerPoint 串接各組，把提示版插入第四組與第六組之間，事先確認黑場及點擊順序。
2. 如使用網頁，投影畫面與操作台應在同一電腦、同一瀏覽器；必須事先排練從 PowerPoint 切到舞台視窗及返回。
3. 排練時確認手機字幕投影可讀、實體長椅與演員走位、音量不蓋住對白，以及各幕的停頓。
4. 音效與配樂只是建議，尚未提供音檔；請確認授權，並在演出設備上測試。
