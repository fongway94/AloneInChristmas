# 《一個人的聖誕》九幕演出流程

37 個畫面皆由操作員手動推進，動畫時間不是演員倒數。以下為演出協作提示；最終對白、時長及走位以導演與排練為準。網頁預錄禱告及旁白在各自畫面約兩秒後播放；PowerPoint 需自行插入 MP3。字幕使用繁體中文。

| 幕 | 畫面與表演節奏 | 聲光及操作 |
|---|---|---|
| 一、孤獨 | 房間想找人說話 → 打字又刪除 → 翻看照片、看空位、抱緊抱枕。 | 草稿自動輸入再刪除；配合演員動作。 |
| 二、現實 | 鬧鐘、穿外套 → 接聽並記錄工作訊息 → 回家拆帳單、查看錢包與計算。 | 鬧鐘、電話及通知聲待補；字幕「生活不會因為我累了，就停下來。」 |
| 三、無法掌控 | 整理帳單、深呼吸 → 接到家人來電 → 扶椅坐下、掩面哭泣 → 最後提問淡黑。 | 家人預錄對白待導演確認；黑場保持到第四幕。 |
| 四、沒有回覆 | 房間暗下 → WhatsApp 群組四則訊息依次出現 → 女孩沒有回覆，躺下拉被。 | 提示聲與孤單音樂待補；留足看訊息和躲進被子的時間。 |
| 五、窗外的聖誕夜 | 被窗外聲音吵醒 → 望向煙花街景、嘆氣搖頭 → 穿外套與圍巾出門。 | 網頁煙花為動態；煙花、人群及聖誕歌曲待補。PPT 煙花為靜態。 |
| 六、人群中的孤獨 | 朋友拍照交換禮物 → 情侶看燈飾 → 家庭帶孩子 → 女孩獨自穿過人群。 | 三組由演員演出；輕快聖誕歌曲待補，字幕後留閱讀時間。 |
| 七、長椅上的禱告 | 女孩坐到已在長椅的男孩身旁，沒有留意他 → 關心與陪伴 → 詢問禱告並獲同意 → 禱告。 | **沒有相撞。**使用實體長椅；禱告約 18.6 秒，網頁自動播放，PPT 請自行插入；溫柔鋼琴待補。 |
| 八、笑容背後的故事 | 「因為耶穌愛你」→ 男孩開始分享 → 過往困境與預錄旁白 → 完整見證 → 字幕。 | 旁白約 15 秒，網頁自動播放；PPT 請自行插入。回憶影像為匿名背影。 |
| 九、因為耶穌愛你 | 鼓勵與擦淚 → 男孩看時間 → 朋友到來 → 邀請、猶豫和點頭 → 一起離開 → 三句結尾字幕。 | 手機提示聲、充滿盼望的音樂待補；每句字幕手動推進，最後一句保持，再手動黑場。 |

## 交接與排練

1. PPT 可插入第四組和第六組之間；確認兩端黑場，並手動插入禱告及旁白音檔。
2. 網頁舞台和操作台須在同一台電腦的同一瀏覽器，練習 PowerPoint 與網頁切換。
3. 提前在舞台視窗互動並測試聲音，調好音量；如由演員現場說禱告或旁白，請先靜音預錄。
4. 檢查長椅、人群動作、字幕投影對比、聲音授權與各幕實際時間。新版內容增加了九幕和預錄，能否控制在約 10 分鐘須排練確認。
