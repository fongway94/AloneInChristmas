# 《一个人的圣诞》九幕演出流程

背景采槟城本地生活与乔治市店屋氛围（生成的想像场景，并非特定街道实拍）；37 个画面皆由操作员手动推进，动画时间不是演员倒数。以下为演出协作提示；最终对白、时长及走位以导演与排练为准。网页预录祷告及旁白在各自画面约两秒后播放；网页音乐与音效会依画面播放；PowerPoint 音频未嵌入，须另行播放或自行插入。现用 AI 普通话声音未指定槟城口音，可改用本地演员录音。字幕使用简体中文，主要字幕以大字置中；请实地检查舞台走位与投影对比。

| 幕 | 画面与表演节奏 | 声光及操作 |
|---|---|---|
| 一、孤独 | 房间想找人说话 → 打字又删除 → 翻看照片、看空位、抱紧抱枕。 | 草稿自动输入再删除，朋友和家庭的聚会照片依次上滑；配合演员动作。 |
| 二、现实 | 闹钟、穿外套 → 接听并记录工作讯息 → 回家拆帐单、查看钱包与计算。 | 工作讯息的时间依次变化，表示一天过去；闹钟及工作讯息提示音自动播放；字幕「生活不会因为我累了，就停下来。」 |
| 三、无法掌控 | 整理帐单、深呼吸 → 接到家人来电 → 扶椅坐下、掩面哭泣 → 最后提问淡黑。 | 家人预录对白待导演确认；黑场保持到第四幕。 |
| 四、没有回复 | 房间暗下 → WhatsApp 群组四则讯息依次出现 → 女孩没有回复，躺下拉被。 | 提示声随四则讯息出现，音乐保持低音量；留足看讯息和躲进被子的时间。 |
| 五、窗外的圣诞夜 | 被窗外声音吵醒 → 望向烟花街景、叹气摇头 → 穿外套与围巾出门。 | 网页烟花为动态；烟花、远处人群和圣诞器乐自动播放。PPT 烟花为静态。 |
| 六、人群中的孤独 | 朋友拍照交换礼物 → 情侣看灯饰 → 家庭带孩子 → 女孩独自穿过人群。 | 三组由演员演出；圣诞器乐和低音量人群环境音自动播放，字幕后留阅读时间。 |
| 七、长椅上的祷告 | 女孩坐到已在长椅的男孩身旁，没有留意他 → 关心与陪伴 → 询问祷告并获同意 → 祷告。 | **没有相撞。**使用实体长椅；祷告约 18.6 秒，网页自动播放，PPT 请自行插入；温柔背景音乐自动减低。 |
| 八、笑容背后的故事 | 「因为耶稣爱你」→ 男孩开始分享 → 过往困境与预录旁白 → 完整见证 → 字幕。 | 旁白约 15 秒，网页自动播放；PPT 请自行插入。回忆画面采男孩的视角，不投影人物。 |
| 九、因为耶稣爱你 | 鼓励与擦泪 → 男孩看时间 → 朋友到来 → 邀请、犹豫和点头 → 一起离开 → 三句结尾字幕。 | 手机提示声和充满盼望的音乐自动播放；夜海、渐现的光束及象征拥抱的第一人称画面依次出现；每句字幕手动推进，最后一句保持，再手动黑场。 |

## 交接与排练

1. PPT 可插入第四组和第六组之间；确认两端黑场，并另行播放音乐、音效、祷告和旁白，或手动插入音档。
2. 网页舞台和操作台须在同一台电脑的同一浏览器，练习 PowerPoint 与网页切换。
3. 提前在舞台视窗互动并测试声音，调好音量；如由演员现场说祷告或旁白，请将“预录人声”调为零，音乐和环境音仍可保留。
4. 检查长椅、人群动作、字幕投影对比、声音授权与各幕实际时间。新版内容增加了九幕和预录，能否控制在约 10 分钟须排练确认。

逐画面音乐、环境声和提示点见 `docs/sound-cues.md`；素材授权见 `docs/audio-sources.md`。实际走位、对白和设备音量须现场试听调整。
