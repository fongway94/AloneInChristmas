# 《圣诞独行》舞台视觉系统

无需后端的双窗口舞台演示原型。默认从黑场待命开始；第一幕约 40 秒，结束后保持黑场，直到操作员推进。所有舞台文案均为简体中文。

## 本地运行与演出

使用静态服务器（不要直接双击 HTML 文件）：例如在项目目录执行 `python3 -m http.server 8000`，打开 `http://localhost:8000/operator.html`。舞台与控制台必须使用**完全相同的来源**（协议、域名和端口）；不要混用 localhost 和 127.0.0.1。

1. 打开操作面板，点击「打开舞台画面」，允许弹出窗口。将舞台窗口移到投影屏，点击舞台窗口后按 **F** 全屏。舞台上没有控件；再次按 F 或 Esc 退出全屏。
2. 切回操作面板，按「下一幕」或右方向键 / 空格开始。画面自动播放并在末尾淡至黑场，黑场一直保持。下一幕将进入后续场景；当前原型只有一幕，因此再次推进后是演出结束黑场。
3. 左方向键返回上一幕；R 重新播放；B 立即黑屏，再按一次解除；播放 / 暂停按钮暂停或继续时间轴。F 全屏**当前获得焦点的窗口**。也可点击列表直接进入对应场景（会重新播放）。
4. 建议演出前在同一浏览器、同一浏览器配置文件中测试双屏、投影比例、音量和快捷键。同步使用 BroadcastChannel，并以 localStorage 事件作为后备；状态会保存在浏览器中，重新打开页面会恢复最近的状态。浏览器隐私限制或禁用站点存储可能影响同步。

## GitHub Pages

项目使用相对路径和原生 ES 模块，可从 GitHub Pages 的仓库子路径直接运行。将分支发布为 Pages 来源，入口为 `index.html`（舞台）和 `operator.html`（操作台）。静态服务器必须提供 JavaScript 模块的正确 MIME 类型。

## 编辑与扩展

- `scenes/scene01.js` 包含场景标题、背景、消息、时间点、总时长、冻结与淡出时间及静音音频配置。消息按 `at`（秒）逐条进入；修改数据即可调整文案和节奏。保持消息时间递增，确保 `freezeAt ≤ fadeAt` 且 `fadeAt + fadeDuration ≤ duration`。
- 新场景可参考第一幕的数据结构，在 `scenes/index.js` 引入并按演出顺序加入数组。当前渲染器专为手机通知场景设计；不同视觉形式需要在 `js/stageDisplay.js` 加入对应渲染器，然后通过场景类型分发。`transitionOut` 和 `pausePoints` 是预留字段，尚未实现通用转场与自动暂停点。
- `js/sceneManager.js` 管理状态、计时和跨窗口同步；`js/stageDisplay.js` 渲染画面；`js/audioManager.js` 管理可选音轨。预览静音，只有舞台窗口播放音频。
- 为 `audio.music` 或 `audio.effects` 指定 `{ src, at, end, volume, fadeIn, fadeOut }`，路径相对页面，时间单位为秒。请自行提供有授权的本地音频。浏览器可能阻止自动播放：有声演出前须在舞台窗口执行用户交互并测试；目前没有音量界面、独立的音频解锁按钮或循环播放。
- `assets/images/morning-room.png` 是为原型生成的背景图；`assets/audio/`、`assets/videos/` 暂无素材。手机和通知为可编辑 HTML/CSS，并非真实手机照片。没有使用第三方音乐或影片。请按实际制作需求替换或补充授权素材。

## 注意

全屏需要用户手势，控制台无法可靠地远程让另一个窗口进入全屏。自动播放计时基于系统时钟，后台标签页会在恢复时追上进度；排练时避免休眠、调整系统时间或关闭站点存储。首次演出前请检查实际投影尺寸及中文字体（优先使用系统中文字体）。
