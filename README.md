# 《一個人的聖誕》｜九幕舞台視覺

依最新劇情製作：九幕、37 個手動推進的畫面，視覺以馬來西亞檳城為背景。每個畫面的主要動畫自動播放；環境會持續緩慢移動，直至操作員配合演員推進。第三幕結尾淡至黑場並保持；第九幕最後一句保持，手動推進後進入黑場。這是演出視覺與提示系統，不會自動取代演員、道具或現場音效。

## 網頁版操作

1. 在演出電腦以同一瀏覽器開啟 `operator.html`，點「打開舞台畫面」，並允許彈出視窗。
2. 將舞台視窗移到投影幕，點一下舞台視窗並按 F 全螢幕。回到操作台，按「下一個畫面」開始。
3. 跟隨操作台的演員提示手動推進；動畫時間只是參考，不會自動跳到下一段。右鍵或空白鍵是下一個畫面，左鍵是上一個，R 重播，B 黑場／解除，F 控制目前視窗全螢幕。
4. 預錄禱告及旁白分別在相應畫面開始約兩秒後播放。操作台可以靜音及調整音量；若要演員現場說話，可先靜音。先點舞台視窗並在正式演出電腦測試音訊；瀏覽器可能阻擋自動播放。重新播放會從該畫面開頭開始。手動黑場只遮住畫面並暫停音訊，不會暫停時間；如需停住時間，請另按「暫停」。
5. 網頁雙視窗使用 BroadcastChannel 與 localStorage 後備同步；必須同一台電腦、相同網站來源及同一瀏覽器設定檔。不能跨手機和電腦同步。

禱告及旁白為經使用者試聽選擇的 AI 普通話聲音：`assets/audio/prayer.mp3` 和 `assets/audio/testimony.mp3`；並不保證檳城口音，可依排練需要改用本地演員錄音。第三幕家人來電的預錄對白、所有其他音效、音樂仍待製作；來電台詞與人聲請導演確認。請使用有授權的音效與音樂，避免蓋過對白。

## PowerPoint 版本

`deliverables/stage-cues.pptx` 有 48 張投影片，包括演出前後黑場。草稿輸入／刪除、工作訊息及 WhatsApp 群組訊息拆成多張手動推進；窗外煙花在 PPT 中是靜態效果。字幕、手機元件及對話文字可編輯，每張投影片的備忘稿有演員與操作提示。

這是**靜態逐頁提示版**，不是網頁的動態影片；手機震動、雨絲、動態煙花及環境運動不會自動播放。禱告和旁白 MP3 **沒有嵌入 PPT**，如需在 PowerPoint 播放，請將上述 MP3 分別插入第七幕「為她禱告」及第八幕「男孩過去的困境」投影片，依現場要求設定開始方式和音量。其他聲音仍待補。PowerPoint「重用投影片」可把整份插入第四組與第六組之間；保留來源格式，按需要移除重複黑場。務必在演出電腦測試順序、中文字體、轉場和音訊。

## 演出與素材

- 女孩直接在長椅坐下，男孩原本坐在旁邊；**不再有相撞情節**。街景不畫人群或長椅，以免與演員衝突；請用配角與實體長椅呈現。
- WhatsApp 群組為劇用模擬畫面，不連接真實聊天服務。朋友 A–D 的訊息與草稿文案可在場景檔編輯。
- 房間、街景、回憶是依檳城公寓、熱帶雨景及喬治市店屋氛圍生成的想像場景，並非特定真實街道的照片；疊加雨絲、燈光、煙花、鏡頭、通知及字幕動畫，並非實拍影片。主要環境採角色所在位置的視角，不投影主角或男孩的身影；朋友聚會照片仍保留人物，因為那是女孩手機裡看到的照片。
- 九幕加預錄、對話、群眾走位與轉場的實際時間須依排練確認；原約 10 分鐘為目標，不保證自動計時能達成。
- 詳細操作與聲光建議見 `docs/stage-rundown.md`。

## 本機、部署與編輯

在專案目錄執行 `python3 -m http.server 8000`，開啟 `http://localhost:8000/operator.html`；不要直接雙擊 HTML。GitHub Pages 以相對路徑部署，`index.html` 是舞台，`operator.html` 是操作台。

九幕分別位於 `scenes/scene01.js` 至 `scene09.js`，在 `scenes/index.js` 排序。可編輯 `description`、`cue`、`caption`、`notifications`、`messages`、`draft`、`duration` 及 `audio`；所有時間單位為秒。`js/atmosphere.js` 包含左側／中央／右側雨絲、街燈與煙花預設。預錄音軌的 `at`、`end` 需和實際檔案長度一起調整，避免切斷或重播。

重新產生 PPT 需 Node.js、Python、`python-pptx`、`Pillow`，執行 `python3 tools/create_powerpoint.py`；此動作會覆寫 PPT，手工修改請先另存。

## 測試及限制

執行 `node --experimental-default-type=module tests/sceneManager.test.mjs`、`node --experimental-default-type=module tests/atmosphere.test.mjs` 和 `node --experimental-default-type=module tests/audioManager.test.mjs`。仍須在演出設備實測 PowerPoint、雙螢幕、中文字體、燈光走位、音訊自動播放與音量。網頁預覽是靜音的，聲音只在舞台視窗播放。
