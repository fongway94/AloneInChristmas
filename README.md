# Alone in Christmas — 《這個聖誕，不再孤單》

聖誕話劇舞台簡報 + tune 後劇本。

- **`index.html`** — 舞台簡報（直接用瀏覽器開啟即可）：投放 PPT 字幕、自動轉背景音樂/音效、顯示對白。全劇只需 **16 個 Cue**，按 `Space` / `→` / 點畫面推進；第六幕三組人群會自動依次出場。頂部按鈕可開關音樂、全螢幕、查看 Cue 表。
- **`SCRIPT.md`** — tune 後完整劇本（九幕，⭐ = 新增氣氛對白）與音樂表、排練提示。

音樂以 Web Audio 即時演奏經典聖誕旋律（平安夜、鈴兒響叮噹、普世歡騰等），毋須任何音樂檔案或網絡。
